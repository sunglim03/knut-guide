# 교통대 꿀팁 가이드

한국교통대 충주캠퍼스 학생들이 모은 맛집·생활꿀팁을 보는 모바일 웹앱입니다. (학생이 만든 비공식 가이드)

## 폴더 구성
- `index.html` : 첫 화면(맛집 / 생활꿀팁) + 맛집 지도 화면
- `css/app.css`, `js/app.js` : 화면 디자인과 동작
- `data/restaurants.js` : 맛집 데이터 (엑셀에서 자동 생성 — 직접 고치지 않기)
- `data/coords.json` : 가게별 지도 핀 좌표 (엑셀의 지도 링크에 접속해 받은 값)
- `tools/build_data.py` : 엑셀 → 앱 데이터 변환 스크립트

## 엑셀을 고쳤을 때
```
python tools/build_data.py "맛집 엑셀 파일 경로.xlsx"
```
새로 추가된 가게만 지도 링크에 접속해 좌표를 받고, 나머지는 `coords.json`에 저장된 값을 씁니다.

## 내 컴퓨터에서 열어 보기
```
python -m http.server 8765
```
실행 후 브라우저에서 http://127.0.0.1:8765 접속.

## 화면 규칙
- 엑셀에 `확인 안됨`인 값은 지어내지 않고 "방문 전 확인 필요"로 보여 줍니다.
- 지도 링크가 검색 링크라 좌표를 못 받은 가게는 같은 건물(도로명+번지)에 있는 다른 가게 위치에 핀을 찍고, 정보 창에 그 사실을 표시합니다.
- 위치를 전혀 알 수 없는 가게는 지도에 찍지 않고 목록에만 보여 줍니다.

## 지도
OpenStreetMap 지도를 Leaflet으로 띄웁니다(무료, 키 필요 없음). 사용자가 많아지면 카카오맵/네이버 지도 API(키 발급 필요)로 바꾸는 것을 권장합니다.
